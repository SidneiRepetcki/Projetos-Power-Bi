O dashboards que criei foi focado em gestão de vendas, utilizando um modelo de dados organizado, aplicação de filtros, segmentações, KPIs e gráficos dinâmicos. No projeto, estruturei o relatório com visualizações que permitiam analisar o desempenho de vendas de forma intuitiva, aplicando um tema personalizado para melhorar a experiência visual. Também integrei a análise com métricas importantes como volume de vendas, faturamento e comparação de períodos, sempre buscando entregar insights claros e fáceis de interpretar para o usuário.
